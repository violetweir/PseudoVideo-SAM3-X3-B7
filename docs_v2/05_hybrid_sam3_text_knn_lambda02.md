# SAM3-enc + Qwen 文本描述混合 KNN（λ=0.2 首版）

> 版本: 2026-08-14
> 状态: 已完成 λ=0.2 的 route graph 与 SAM3 base @256 评估

## 1. 方法

- 主 KNN 特征：SAM3-enc @1008 `target_pooling + patch_mean`
- 辅助特征：Qwen3.5 文本描述 one-hot 向量的 cosine 相似度
- 路径转移分数：

```text
transition = (1 - λ) * SAM3_patch_mean_sim + λ * Qwen_text_sim
λ = 0.2
```

## 2. 结果

| 口径 | direct | b1 | b2 | b3 | b4 | b5 | b6 | 最强桥 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| validation | 0.8330 | 0.8404 | 0.8373 | 0.8656 | 0.8708 | 0.8672 | **0.8816** | b6 0.8816 |
| test | 0.8205 | 0.8808 | 0.8824 | **0.8929** | 0.8765 | 0.8841 | 0.8684 | b3 0.8929 |

## 3. 对比

| 方法 | validation 最强 | test 最强 |
|---|---:|---:|
| Qwen 纯文本 KNN | 0.8308 | 0.8394 |
| SAM3-enc 纯视觉 KNN | 0.8430 | 0.8874 |
| **SAM3-enc + Qwen 文本 λ=0.2** | **0.8816** | **0.8929** |
| SAM3-enc base b0-b6 fusion | 0.8515 | 0.8979 |

结论：

- 混合文本相似度后，固定桥最高从 0.8874 提升到 0.8929；
- validation 提升更明显，从 0.8430 提升到 0.8816；
- 仍略低于 b0-b6 fusion 的 0.8979，但文本信息是有效辅助信号；
- 下一步可调 λ，并对混合路线候选做 b0-b6 fusion，目标超过 0.8979。
